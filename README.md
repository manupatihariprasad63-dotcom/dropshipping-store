# Velora

Velora is a premium hoodie e-commerce storefront template designed for international sales. It includes:

- responsive storefront layout
- product catalog and featured products
- cart and checkout flow
- WhatsApp ordering support
- contact form placeholder for Formspree

## Files
- `index.html` — home page
- `shop.html` — product catalog
- `about.html` — about page
- `contact.html` — contact page
- `products.json` — product inventory
- `styles.css` — styling
- `app.js` — store logic

## Setup
1. Clone the repo.
2. Replace product data in `products.json` with your actual products and prices.
3. Replace `YOUR_FORM_ID` in the contact form and checkout code with your Formspree endpoint if you want form submissions.
4. Publish the site using GitHub Pages or Netlify.

## Deploy to GitHub Pages
1. Push the repo to GitHub.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Choose the `main` branch and root folder (`/`).
5. Save. GitHub will generate a live URL.

## Deploy to Netlify
1. Import the repo into Netlify.
2. Set the publish directory to the repo root.
3. Deploy.
